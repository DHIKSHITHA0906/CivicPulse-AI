\# CivicPulse AI



CivicPulse AI is a multilingual citizen-demand platform that combines citizen requests, real infrastructure data, and existing government investment to generate explainable infrastructure priorities.



\## Team Modules



\- M1 — Gemini AI / structured extraction

\- M2 — Data / Priority / Investment

\- M3 — Backend / Firestore / Deployment

\- M4 — Frontend / Map / Demo UX



\## Architecture



Frontend → FastAPI → Firestore → Gemini + Priority Engine
